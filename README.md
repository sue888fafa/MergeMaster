# 占城大师：Godot 简化版

这是一个 Godot 4.x 2D 单机原型，复刻六边形领地争夺、自动出兵和路线封锁的核心循环。

## 运行

1. 使用 Godot 4.x 导入本目录。
2. 打开 `Main.tscn`。
3. 点击运行项目。

操作方式：点击己方领地旁边的地块即可购买。点击主城或己方兵营可查看 5 格攻击范围；长按有同职业同等级兵营的兵营，再拖到高亮目标上完成合成。士兵和敌方 AI 会自动行动。

## 规则

- 玩家和 AI 初始拥有 0 金币，每 5 秒获得 5 金币；金矿每 5 秒为所属方增加 3 金币。
- 兵营每 10 秒尝试生成一名所属职业士兵，只有攻击范围内存在敌方士兵、建筑或主城时才会出兵。
- 游戏包含坦克、战士、法师、刺客和弓箭手五种职业，兵营合成必须满足同职业、同等级。
- 部队只能在已经翻开的地块上推进，抵达空地或敌方地块后自动占领。
- 摧毁敌方主城，或 180 秒结束时占领更多地块即可获胜。
- 所有主要数值集中在 `main.gd` 和 `unit.gd` 中，方便后续校准。

## 当前限制

本版本不包含卡牌、阵营羁绊、神器、随机地图、多人联机和局外养成。项目使用程序绘制图形，不包含原游戏素材。
